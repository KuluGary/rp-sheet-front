# Roleplay Sheet

A React application for creating and managing TTRPG character sheets with support for multiple game systems.

## Supported Systems

- **D&D 5e** - Full character sheet with stats, features, spells
- **FATE Core** - Aspects, skills, and stunts
- **Ironsworn** - Character assets and progress tracking
- **Kids on Bikes** - Simplified character management

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- React Spring (animations)

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- ✨ Multi-system support
- 💾 Local file management (import/export)
- 🎨 Responsive design
- ⚡ Fast performance with Vite
- 📝 Form validation with Zod schemas
